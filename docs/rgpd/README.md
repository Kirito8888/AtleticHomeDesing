# Documentación RGPD de una instalación de LifeOS

**Uso personal (solo tú, o cuentas de prueba con datos inventados):** te cubre la exención doméstica del RGPD (art. 2.2.c) y no necesitas estos documentos. Aun así, conviene tenerlos preparados.

**En cuanto otras personas usen tu instalación con datos reales** (tu entrenador/a, otras atletas, una amiga como contacto de «Entreno sola»), eres **responsable del tratamiento**. Además tratas datos de salud, que son categoría especial (art. 9). Entonces necesitas:

| Documento | Para qué | Plantilla |
|---|---|---|
| Registro de actividades de tratamiento (RAT) | Art. 30. Qué datos tratas, para qué, cuánto tiempo y con qué medidas. | [`registro-actividades.md`](registro-actividades.md) |
| Evaluación de impacto (EIPD) | Art. 35. Obligatoria con datos de salud a cierta escala; recomendable siempre que los trates. | [`eipd.md`](eipd.md) |
| Contrato de encargado | Art. 28. Si alguien trata datos por cuenta tuya, p. ej. quien te administra el servidor. | [`contrato-encargado.md`](contrato-encargado.md) |
| Política de privacidad | Arts. 13 y 14. Ya la genera la app en `/legal/privacidad` con `LEGAL_NAME`, `LEGAL_EMAIL`… | — |
| Registro de brechas y plan de respuesta | Art. 33. | [`../seguridad-incidentes.md`](../seguridad-incidentes.md) |

Estas plantillas no son asesoramiento jurídico. Para un uso con terceros de cierta entidad, revísalas con un profesional. La AEPD tiene la herramienta gratuita **Facilita RGPD** para casos sencillos.
